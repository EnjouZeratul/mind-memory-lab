# DESIGN — mind-memory-lab Web

本文件约束 `apps/web` 的可见层样式与语气。当前视觉参考 **DeepSeek 类对话产品**：扁平近黑/纯白底、低对比分隔、**蓝紫主操作**、圆角会话气泡与**底部一体输入条**（圆角容器 + 内嵌输入 + 主按钮），避免花哨渐变与装饰性描边。

## 布局

- 根壳 `100dvh`；对话区侧栏 + 主列铺满；消息与输入区 `max-width` 居中以保证可读宽度。
- 顶栏：主导航 + 外观（深/浅/系统）。对话内可收起会话列表。

## 主题

- **深色**：`#0d0d0d` 级背景，侧栏略抬一级灰；主文字 `#ececec`，次文字 `#8c8c8c`。
- **浅色**：白底与浅灰侧栏，主文字近黑。
- 主按钮与焦点环使用同一套 **`--accent`**（蓝紫），与记忆库等页内主按钮一致。

## 对话交互

- **Enter** 发送，**Shift+Enter** 换行（与常见网页对话一致）。
- 用户消息为右侧对齐的圆角灰气泡；助手为左对齐正文色，弱化「卡片感」。

## 用户可见文案（语气）

- 与 [`docs/project-conventions.md`](../../docs/project-conventions.md) 一致：理性、客观、可检验。
- **禁止**把 `docs/` 架构说明搬进界面；空状态与侧栏只用短标签。

## 信息架构

- **对话**：`POST /api/chat/stream`；引用与工具折叠块随流更新。若模型返回思考分段，助手气泡上方提供可折叠「思考过程」块（生成中默认展开，结束后可收起）；规格见 [`docs/runtime-and-data-flow.md`](../../docs/runtime-and-data-flow.md)。
- **记忆库 / 检索 / 详情**：行为不变，随明暗主题统一表面色。
